# autocheck-team

Система автоматической проверки программных решений студентов: загрузка исходного кода,
компиляция и запуск в изолированной среде, прогон тестов с ограничением времени и памяти,
сохранение результатов и отчёт об ошибках.

Проектный практикум, защита 1 декабря 2026.

| Репозиторий | Что внутри |
|---|---|
| [backend](https://github.com/autocheck-team/backend) | Go 1.27: API, воркер проверки, миграции PostgreSQL |
| [frontend](https://github.com/autocheck-team/frontend) | React + TypeScript |
| [infra](https://github.com/autocheck-team/infra) | docker compose для всей системы, деплой, архитектура |

Задачи: [GitHub Project](https://github.com/orgs/autocheck-team/projects).
