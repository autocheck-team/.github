# Как вносить изменения

Правила общие для всех репозиториев autocheck-team.

## Задачи

Вся работа идёт через issues и [GitHub Project](https://github.com/orgs/autocheck-team/projects).
Перед началом работы назначь issue на себя и переведи в **In Progress**.

## Ветки

Работаем по GitHub flow: `main` всегда рабочий, всё остальное — короткие ветки от `main`.

Имя ветки: `<тип>/<номер-issue>-<кратко>`, например `feat/12-submission-upload`, `fix/31-oom-verdict`.
Типы: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `ci`.

## Коммиты

[Conventional Commits](https://www.conventionalcommits.org/ru/): `feat: приём посылок через API`,
`fix(worker): вердикт ML при OOM`. Можно по-русски.

## Pull request

1. Открывай PR рано, черновиком (Draft), если работа не закончена.
2. В описании укажи `Closes #<номер>`: issue закроется после мёржа.
3. В `main` нельзя пушить напрямую. Мёрж только через PR, после того как прошли все обязательные проверки CI.
4. Мёрж только **Squash and merge**. Заголовок PR становится сообщением коммита, поэтому он тоже
   пишется по Conventional Commits.
5. Ветка удаляется автоматически после мёржа.

Ревью от второго участника приветствуется, но не обязательно: в команде по одному человеку
на бэкенд и фронтенд.
